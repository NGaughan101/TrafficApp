TrafficApp

Setup Instructions

Clone or download this repository:

git clone https://github.com/NGaughan101/TrafficApp.git

Open the project in Android Studio and allow Gradle to sync.

In the project root directory, create or edit the local.properties file.

Add the following API credentials:

MY_MAPS_KEY=YOUR_MAPS_KEY
MY_DATEX_KEY=YOUR_DATEX_KEY
MY_DATEX_ID=YOUR_DATEX_ID

Replace the placeholder values with the API credentials provided to you.

Sync the project and run the application.

Note: Do not commit or upload local.properties to GitHub. It is excluded through .gitignore.
